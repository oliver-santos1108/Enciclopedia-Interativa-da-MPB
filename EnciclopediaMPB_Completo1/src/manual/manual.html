Manual de uso - Enciclopédia Interativa da MPB

1. Objetivo

O sistema permite cadastrar, consultar, editar e excluir artistas da Música Popular Brasileira.

2. Cadastrar um artista

  1. Acesse Cadastro.
  2. Preencha nome, ano de nascimento, quantidade de álbuns, álbuns e local de nascimento.
  3. O ano de falecimento é opcional.
  4. Se desejar, escolha uma fotografia. Ela será reduzida e armazenada no banco.
  5. Clique em Salvar.

3. Consultar e editar

Acesse Consulta, digite parte do nome e clique em Pesquisar. Para ver todos os artistas, clique em Mostrar todos. Clique em uma linha para abrir os dados no formulário. Altere os campos e clique em Salvar para atualizar.

4. Excluir

Selecione um artista na consulta, confirme a exclusão e o registro será removido.

5. Fotografias

As imagens são opcionais. O sistema reduz a imagem mantendo a proporção e grava seus bytes na coluna foto (LONGBLOB). A listagem não carrega as fotos; a foto é consultada somente quando o artista é selecionado.

6. Menu

  • Arquivo > Limpar campos: inicia um cadastro vazio.
  • Arquivo > Sair: encerra o programa.
  • Ajuda > Sobre: mostra os dados do software.
  • Ajuda > Manual de uso: abre esta documentação.

7. Requisitos

  • Java 8 ou superior.
  • MySQL em execução.
  • Banco mpb e tabela artista.
  • MySQL Connector/J adicionado ao Build Path do Eclipse.
