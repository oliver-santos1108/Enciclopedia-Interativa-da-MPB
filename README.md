## 🚀 Instalando Enciclopédia Interativa da MPB

Para instalar o projeto, siga estas etapas:

No terminal do Git Bash rode: 
```
git clone https://github.com/oliver-santos1108/Enciclopedia-Interativa-da-MPB.git
```
Abra a pasta `EnciclopediaMPB_Completo1` no Eclipse

No MySQL, rode o banco de dados presente no arquivo `mpb.sql`

Rode o arquivo `Main` e explore o sistema!
